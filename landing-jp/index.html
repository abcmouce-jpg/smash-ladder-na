Smash Ladder JP

日本のスマブラSP向け、レート対戦のマッチングサイトです。

これは何か

スマメイトのサービス終了を受けて、日本向けのレート対戦サイトを開発しています。 北米で稼働している Smash Ladder と同じ基盤を使い、ルールは日本のコミュニティに合わせて決めています。

Discord でログインして待機すると、レートの近い相手と自動でマッチングします。 対戦が決まってからステージのBAN、結果の報告までは画面が順番に案内します。

決まっていること

  • 低遅延Mod（ディレイMod）の使用は禁止します。改造していない本体でプレイしてください。回線を良くしたい場合は有線LANアダプタを使ってください。有線の相手だけとマッチングする設定も用意します。
  • 賞金はありません。シーズンは順位をつける期間で、賞金を懸けたイベントではありません。
  • マッチングは全国一律です。距離で相手を絞りません。都道府県はランキングとプロフィール用です。
  • レートは Elo です。自分で計算して確かめられる増減にしています。
  • 対戦は 2先（Bo3）、ステージギミックはオフです。
  • ステージのBANはありません。スマメイトのルールに準じます。
    1戦目：お互いがゲーム内で戦いたいステージを選び、抽選の結果に従います（「おまかせ」は選ばないでください）。
    終点 / 戦場 / ポケスタ2 / 小戦場 / ホロバス / 村と町 の6つから。
    2・3戦目：直前の敗者が選び、勝者は「おまかせ」を選択します。ここに すま村 が加わって7つになります。
    「終点」「戦場」は、終点化・戦場化したステージとしても選べます。

公開について

現在開発中です。公開日が決まり次第、Discord と X でお知らせします。テスターや、日本のコミュニティとのつなぎ役を探しています。
